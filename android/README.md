# Lullaby Launcher для Android

Приложение-компаньон: чат с Лунни, который собирает сборки модов прямо на телефоне.

- Лунни понимает запросы так же, как в лаунчере на компьютере (правила, словарь и стоп-слова
  генерируются из `launcher/modplatform/agent` скриптом `tools/gen_rules.py`): темы, названия модов,
  «убери / без», «побольше», непонятные слова.
- Моды берутся с **Modrinth**: проверка версии Minecraft и загрузчика (NeoForge, Forge, Fabric, Quilt),
  оптимизация и удобство, моды по темам (только действительно про тему), все обязательные библиотеки,
  без дублей и несовместимых модов. Если для версии нет модов по теме, Лунни подсказывает, где они есть.
- Каждый разговор сохраняется («Чаты»): можно вернуться и продолжить, переименовать или удалить.
- Готовую сборку можно открыть в лаунчере Minecraft для Android, который умеет ставить сборки
  Modrinth (`.mrpack`), отправить файлом или сохранить.
- «⋮ → Код приглашения друга» расшифровывает код `LL-…` (или старый `SC-…`) из «Моего сервера» на компьютере в адрес и порт.

- **Вход через Microsoft**: меню открывается только после входа. Код вводится на microsoft.com/link
  (на телефоне или компьютере), дальше Xbox Live → Minecraft: ник, скин и проверка, что Java Edition куплена.
  При следующем запуске вход обновляется сам. Приложение Microsoft то же, что у лаунчера на компьютере.
- **Главное меню как на компьютере**: установки, «Моды и ресурсы», «Готовые сборки», «Новая установка».
- Моды, ресурспаки и шейдеры ставятся с **Modrinth** и с **CurseForge** (переключатель в поиске).
  Файлы CurseForge нельзя ссылками класть в `.mrpack`, поэтому они едут внутри сборки (`overrides/`);
  моды, которые автор запретил скачивать мимо приложения CurseForge, не ставятся (библиотеки тогда берутся с Modrinth).
- **Управление в игре**: джойстик для ходьбы и кнопки ЛКМ, ПКМ, прыжок, присесть, смена вещи, инвентарь,
  выбросить, камера (F5), чат, пауза, клавиатура на экране и мышь. Размер, прозрачность и режим для левши
  настраиваются; «Отправить в лаунчер» передаёт схему (формат PojavLauncher v8) в PojavLauncher/Amethyst.

Оформление как у лаунчера на компьютере: ночное небо, большая луна, полупрозрачная радуга и звёзды.

**Как поиграть на телефоне.** Сама Minecraft: Java Edition на Android запускается в отдельном Java-лаунчере
(PojavLauncher, Amethyst, Fold Craft Launcher, Zalith Launcher): в нём есть Java для Android и замена графики,
которых нет в обычном приложении. Кнопка **«Играть»** сохраняет сборку в «Загрузки/Lullaby» (`.mrpack`),
находит установленный Java-лаунчер и открывает его; дальше в лаунчере «Импорт сборки» → этот файл, вход
аккаунтом Microsoft с купленной Java Edition → «Играть». Если лаунчера нет, кнопка ведёт в Google Play.

Приложение работает в **горизонтальном** экране (поворачивается вслед за телефоном): слева чат,
справа готовая сборка с большой кнопкой «Играть». Иконка **адаптивная** (Android 8+): ночное небо
с радугой занимает весь значок, спящий месяц с нотами крупно поверх; телефон сам задаёт её форму.
Картинки иконки — `art/*.svg`, их пишет `program_info/moon_icon.py`.

## Сборка APK

Нужны только пакеты Ubuntu/Debian (без Gradle и без Android SDK от Google):

    sudo apt install aapt android-sdk-platform-23 dalvik-exchange zipalign apksigner openjdk-17-jdk-headless
    ./build-apk.sh

Получится `LullabyLauncher.apk`. Подпись: `release.jks` с паролем в `KEYSTORE_PASS`, если файл есть,
иначе ключ, созданный один раз в `build/debug.jks`. Обновить уже установленное приложение можно только
APK с той же подписью.
