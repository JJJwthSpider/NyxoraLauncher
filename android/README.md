# Lullaby Launcher для Android

Приложение-компаньон: чат с Лунни, который собирает сборки модов прямо на телефоне.

- Лунни понимает запросы так же, как в лаунчере на компьютере (правила, словарь и стоп-слова
  генерируются из `launcher/modplatform/agent` скриптом `tools/gen_rules.py`): темы, названия модов,
  «убери / без», «побольше», непонятные слова.
- Моды берутся с **Modrinth**: проверка версии Minecraft и загрузчика (NeoForge, Forge, Fabric, Quilt),
  оптимизация и удобство, моды по темам (только действительно про тему), все обязательные библиотеки,
  без дублей и несовместимых модов. Если для версии нет модов по теме, Лунни подсказывает, где они есть.
- Каждый разговор сохраняется («Чаты»): можно вернуться и продолжить, переименовать или удалить.
- Готовую сборку можно открыть в лаунчере Minecraft для Android, который умеет ставить сборки
  Modrinth (`.mrpack`), отправить файлом или сохранить.
- «⋮ → Код приглашения друга» расшифровывает код `LL-…` (или старый `SC-…`) из «Моего сервера» на компьютере в адрес и порт.

Оформление как у лаунчера на компьютере: ночное небо, большая луна, полупрозрачная радуга и звёзды.

Сама Minecraft: Java Edition на телефоне запускается в отдельном лаунчере для Android:
это приложение собирает для него сборку.

## Сборка APK

Нужны только пакеты Ubuntu/Debian (без Gradle и без Android SDK от Google):

    sudo apt install aapt android-sdk-platform-23 dalvik-exchange zipalign apksigner openjdk-17-jdk-headless
    ./build-apk.sh

Получится `LullabyLauncher.apk`. Подпись: `release.jks` с паролем в `KEYSTORE_PASS`, если файл есть,
иначе ключ, созданный один раз в `build/debug.jks`. Обновить уже установленное приложение можно только
APK с той же подписью.
