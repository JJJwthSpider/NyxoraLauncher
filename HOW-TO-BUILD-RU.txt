КАК СОБРАТЬ Vellora Client НА WINDOWS
========================================

Если нужно просто играть - собирать не надо. Скачай VelloraClient-Windows.zip,
распакуй его куда угодно и запусти vellora.exe. Это уже готовый лаунчер.

Сборка из исходников:

0. Сначала РАСПАКУЙ ВЕСЬ архив VelloraClient-src.zip: правой кнопкой по архиву,
   «Извлечь все...», «Извлечь». Не запускай build-windows.bat прямо из архива -
   тогда Windows достаёт только один этот файл, без исходников, и сборка
   остановится с ошибкой «CMakePresets.json не найден».

1. В распакованной папке дважды щёлкни по файлу  build-windows.bat.
   Если Windows спросит «Защитник Windows предотвратил запуск» - нажми
   «Подробнее» -> «Выполнить в любом случае».

2. В первый раз скрипт поставит недостающие программы (Git, CMake, Python,
   Java JDK 17, компилятор C++). Windows может спросить разрешение - соглашайся.
   Java для игры в Minecraft не подходит для сборки: нужен JDK (с компилятором
   javac), его скрипт найдёт или поставит сам.
   Когда он напишет «ЗАКРОЙ это окно и запусти build-windows.bat ЕЩЁ РАЗ» -
   закрой окно и снова дважды щёлкни по build-windows.bat.

3. Второй запуск скачает Qt и библиотеки и соберёт лаунчер.
   Это долго (30-90 минут в первый раз), компьютер можно не трогать.

4. Когда появится «ГОТОВО!», откроется папка C:\Vellora\Vellora Client,
   а на рабочем столе будет ярлык «Vellora Client». Запускай его.

Нужно: Windows 10 или 11, интернет, около 10 ГБ свободного места на диске C:.

Если что-то пошло не так - сделай скриншот окна и пришли его.
Подробный журнал сборки: C:\Vellora\build-log.txt
